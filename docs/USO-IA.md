# Uso de IA — Front End

Codex/OpenAI foi utilizado para elaborar a SPA React/Vite/TypeScript/Tailwind, ilustração SVG, mensagens, documentação e verificações locais. Foram executados build TypeScript/Vite e verificações no navegador. Dados do grupo foram fornecidos pelo usuário. Os integrantes devem revisar, compreender e registrar as próprias adaptações antes da entrega. Não foi realizada pesquisa de campo; os registros demonstrativos são sintéticos.

O Front End consome a API Java por Fetch. A API é entregue separadamente na disciplina de Java e não integra este repositório.
