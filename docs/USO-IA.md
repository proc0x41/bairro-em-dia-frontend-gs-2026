# Uso de IA — Front End

Codex/OpenAI foi utilizado como ferramenta de apoio ao desenvolvimento do projeto. Auxiliou na elaboração e revisão de trechos de código dos componentes React/Vite/TypeScript/Tailwind, na ilustração SVG e nas mensagens da interface. Também ajudou na organização da documentação e nas verificações de funcionamento e integração com a API Java.

Os resultados e limites das verificações estão registrados em CONFERENCIA-ENTREGA.txt e na pasta evidencias. Não foi realizada pesquisa de campo; os registros demonstrativos são sintéticos.

O Front End consome a API Java por Fetch. A API é entregue separadamente na disciplina de Java e não integra este repositório.
